# Guide WeWill — Clients et Apprenants

> Documentation pour les clients B2B et les apprenants de l'Academie Mission Formations.
> Le widget de chat est accessible sur toutes les pages de la plateforme.

---

## 1. Utiliser le chat

### Ouvrir le chat

- Cliquez sur la **bulle bleue** en bas a droite de n'importe quelle page
- La fenetre de chat s'ouvre
- Tapez votre message et appuyez sur Entree

### Premieres questions automatiques

Avant de parler a un agent, vous pouvez etre invite a renseigner :
- Votre **nom**
- Votre **email**
- Le **sujet** de votre demande

Cela permet a l'equipe de vous repondre plus rapidement.

### Suggestions rapides

Des boutons de suggestions apparaissent pour les questions les plus courantes :
- "Cours introuvable"
- "Mon certificat"
- "Connexion"
- "Financement"

Cliquez sur un bouton pour envoyer la question directement.

### Horaires de reponse

| Quand | Delai de reponse |
|-------|-----------------|
| Lundi-Vendredi 9h-18h | Moins de 5 minutes |
| Soir et week-end | Sous 24h ouvrables |

Si l'equipe est absente, laissez un message — vous recevrez une reponse par email.

## 3. Pour les entreprises clientes (B2B)

### Demandes specifiques entreprise

En tant que responsable RH ou formation d'une entreprise cliente,
vous pouvez utiliser le chat pour :

| Demande | Description |
|---------|-------------|
| **Inscription de collaborateurs** | Envoyer la liste des employes a inscrire (nom, email, formation) |
| **Suivi de progression** | Demander un point sur l'avancement de vos equipes |
| **Rapport de formation** | Demander un rapport PDF Qualiopi-compatible |
| **Attestations** | Demander les attestations de formation pour vos salaries |
| **Modification de contrat** | Ajouter des sieges, prolonger le contrat, changer de formation |
| **Probleme d'acces** | Un collaborateur ne peut pas se connecter |
| **Facturation** | Questions sur les factures, echeancier, avoir |
| **Devis** | Demander un devis pour de nouvelles formations |

### Informations a fournir

Pour accelerer le traitement de votre demande, indiquez :
- Le **nom de votre entreprise**
- Votre **nom et fonction** (RH, responsable formation, etc.)
- Le **nom de la formation** concernee
- Les **noms et emails** des collaborateurs concernes (si applicable)

### Delais de traitement B2B

| Type de demande | Delai |
|-----------------|-------|
| Inscription collaborateur | Sous 24h |
| Rapport de formation | 48h ouvrables |
| Attestation de formation | 48h ouvrables |
| Devis | 24h ouvrables |
| Modification de contrat | 48-72h ouvrables |
| Support technique | Sous 2h ouvrables |

## 4. Recevoir les reponses par email

Si vous quittez la page avant d'avoir recu la reponse :
1. La reponse de l'agent vous est envoyee par **email**
2. Cliquez sur le lien dans l'email pour reprendre la conversation
3. Vous pouvez aussi repondre directement par email

### Notifications

- Vous recevez un email a chaque reponse de l'equipe
- L'objet de l'email contient le numero de conversation
- L'historique complet est accessible en cliquant sur le lien

## 7. Questions frequentes sur le chat

**Le chat est-il securise ?**
Oui. Les messages sont chiffres en transit (HTTPS). Les donnees sont hebergees sur nos serveurs en France (OVH).

**Mes messages sont-ils conserves ?**
Oui, l'historique est conserve pour assurer le suivi de votre demande. Vous pouvez demander la suppression de vos donnees (RGPD) a tout moment.

**Puis-je envoyer des fichiers ?**
Oui, vous pouvez joindre des captures d'ecran ou documents (PDF, images) directement dans le chat.

**Le chat fonctionne-t-il sur mobile ?**
Oui, le widget est responsive et fonctionne sur tous les navigateurs mobiles.

**Je ne vois pas la bulle de chat**
Desactivez votre bloqueur de publicites (uBlock, AdBlock) qui peut bloquer le widget. Essayez aussi un autre navigateur.
